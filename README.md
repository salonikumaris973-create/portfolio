# Personal Portfolio Website

A modern and responsive portfolio website built using **HTML, CSS, and JavaScript** to showcase skills, projects, resume, and contact information. The website features smooth scrolling, interactive animations, hover effects, and a clean user interface that works seamlessly across desktop, tablet, and mobile devices.

## 🚀 Features

* Responsive design for all screen sizes
* Modern and clean user interface
* Smooth scrolling navigation
* Interactive hover effects
* Animated page elements
* About Me section
* Skills showcase
* Projects gallery
* Resume download option
* Contact form and contact information
* Easy to customize and maintain

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📖 Sections Included

### Home

A welcoming hero section with an introduction and call-to-action buttons.

### About

Provides information about the developer, background, and career goals.

### Skills

Displays technical and professional skills.

### Projects

Showcases completed projects with descriptions and links.

### Resume

Allows visitors to download or view the resume.

### Contact

Contains contact details and a contact form for communication.

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/portfolio-website.git
```

2. Open the project folder.

3. Run `index.html` in your browser.

No additional installation is required.
